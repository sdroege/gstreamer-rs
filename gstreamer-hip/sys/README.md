# gstreamer-hip-sys

FFI bindings for the GStreamer HIP library.

Requires GStreamer 1.30 or newer with HIP support.
The bindings are generated from GstHip GIR using the repository's `generator.py`.
APIs requiring handwritten bindings are intentionally deferred in this initial version.

See the [repository README](https://gitlab.freedesktop.org/gstreamer/gstreamer-rs)
for build requirements and usage information.
